One-line: The condensed uppercase kicker that introduces a section, sitting directly above a heading.

```jsx
import { Eyebrow } from "./Eyebrow";

<Eyebrow>Programmes</Eyebrow>
<Eyebrow tone="inverse">Why Momentum</Eyebrow>   {/* on dark backgrounds */}
<Eyebrow tone="muted" tick={false}>Est. 2018</Eyebrow>
```

Tones: `accent` (Momentum blue, default), `muted` (grey), `inverse` (electric, for dark sections). `tick` toggles the small leading dash. Pair every major section heading with one.
